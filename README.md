## 制作メモ / 技術ノート

- **説明動画の圧縮は ffmpeg を使用**（`-c:v libx264 -b:v 2400k -c:a copy -movflags +faststart`）。
  音声を再エンコードせずコピーすることで、冒頭の音切れ・音ズレを防止。
- **動画差し替え時はファイル名を変更**（`ordia_video` → `ordia_video2` → `ordia_video3` …）してブラウザ／CDNキャッシュを回避。
- 説明動画HTMLは録画用に **無音モード `?silent=1`** ／ **自動再生モード `?auto=1`** を備える。
